## 0. 한 줄 정의

마이크로 내 목소리를 실시간 측정해, **게임을 하듯** 고음 음역을 한 반음씩 넓혀 가는 웹앱. 차별점은 ① 성구 전환(갈라짐) 계측, ② 음표 컬렉션으로 보이는 음역 성장, ③ 게임 규칙에 녹인 발성 부하 관리(목 에너지).

### 비목표 (만들지 않는 것)
- 곡 반주·노래방 기능, 가수 음역 비교, 소셜/랭킹, 로그인·서버, 결제
- 녹음 파일 저장·업로드 (측정 수치만 저장)
- "진단·치료·처방" 표방 — 교육·연습용 웰니스 앱으로 포지셔닝

## 1. 사용자와 핵심 루프

**페르소나**: 20–40대, 노래방에서 고음이 막히거나 갈라짐. 하루 10–15분, 휴대폰으로 연습. 음악 이론 모름.

**첫 실행 (약 5분)**
온보딩 → 마이크 권한·소음 측정 → 기준 발성 → 음역 측정 → 결과(내 음역 키보드 + 첫 목표음) → 첫 게임

**일상 루프 (10–15분)**
```
홈(오늘의 퀘스트 3개) → 버블 워밍업(필수, 고음 게임 잠금 해제)
 → 사이렌 / 음계 등반 (목 에너지 소모) → 결과(XP·새 음 획득)
 → 쿨다운(선택) → 자가체크 3문항 → 코치 피드 메시지
```

**리텐션 장치**: 주간 스트릭(매일 아님, 과사용 방지) · 음표 컬렉션 · 레벨 언락 · 주간 보스전(v2)

## 2. 게임 설계

### 2.1 코어 판정 (모든 게임 공통)
| 난이도 | 허용 오차 | 유지 시간 | 사이렌 튜브 폭 |
|---|---|---|---|
| Easy | ±50 cents | 0.8 s | ±100 cents |
| Normal (기본) | ±35 cents | 1.5 s | ±60 cents |
| Hard | ±20 cents | 2.5 s | ±35 cents |

- 유지 타이머는 허용 오차 안에서만 누적. **150 ms 이내 이탈은 유예**(리셋 안 함).
- 난이도 자동 조정: 같은 게임 3라운드 연속 성공률 ≥ 85% → 한 단계 상향 제안, ≤ 40% → 하향 제안(사용자 확인).

### 2.2 게임 목록

#### A. 버블 워밍업 (Bubble) — MVP · 필수
- 목적: SOVT(빨대·립트릴·허밍) 워밍업. 오늘 이 게임을 끝내야 고음 게임이 열림.
- 화면: 화면 아래 빨대에서 거품이 올라옴. 소리를 내는 동안 거품 생성, **피치 안정도**(1 s 창 F0 표준편차)가 낮을수록 큰 거품.
  - SD < 30 cents → 큰 거품, 30–80 → 중간, > 80 → 작은 거품
- 완료 조건: 누적 유성음 **90 s**. 변형 모드: 화면의 완만한 파도선을 따라 피치 글라이드.
- 보상: XP 20, "오늘 워밍업 완료" 배지 → 홈 상태 갱신.

#### B. 사이렌 슬라이더 (Siren Slide) — MVP
> [검수 반영] 크랙/전환 구간은 검증 전까지 '음정 추적 끊김(원인 미확인)'으로만 표시하고 콤보 리셋·'매끈' 보너스·'전환 구간 집중' 모드에서 제외한다(결정 D2, §11).
- 목적: 성구 전환 구간(passaggio)을 끊김 없이 통과.
- 화면: 가로 스크롤 튜브. y축 = 반음 스케일. 경로 = 편한 저음 → `comfortMax` → 다시 저음, 1회 6–8 s, 라운드당 5회.
- 측정 결과의 **전환 구간을 반투명 띠로 표시**(라벨 "전환 구간").
- 점수: 튜브 안 프레임 비율(%) × 100. 튜브 안 0.5 s마다 콤보 +1.
- **크랙 감지**(§4.6) 시 "삐끗" 이펙트 + 콤보 리셋. 크랙 0회 글라이드 = "매끈" 보너스 +20.
- 단계 3 이후 "전환 구간 집중" 모드: 경로가 전환 구간 ±3반음만 반복 왕복.

#### C. 음계 등반 (Pitch Climber) — MVP · 핵심 게임
> [검수 반영] MVP에서는 '목표음 3회 성공 → `comfortMax += 1`' 자동 상향을 보류한다. 상한은 사용자가 낮추는 것만 상시 허용하고, 하트 0은 실패 페널티가 아닌 휴식 카드로 바꾼다(결정 D1, §11).
- 목적: 음역 사다리. 한 반음씩 올라가 새 음을 획득.
- 화면: 오리지널 캐릭터(작은 음표 모양 마스코트, 자체 제작 SVG)가 반음 단위 발판을 오름. 발판 위 링이 유지 시간만큼 채워지면 다음 발판으로 점프.
- 진행: `comfortMax − 4`부터 시작 → 최상단 발판 = **목표음(`comfortMax + 1`)**.
- 콜앤리스폰스: 기준음 0.8 s 재생 → 200 ms 무음 → 사용자 발성 창(이어폰 모드는 기준음 지속 가능, §4.7).
- 하트 3개. 발판 유지 실패(창 4 s 내 미달성) 시 하트 −1.
- **새 음 획득 규칙**: 한 세션 안에서 목표음 유지 성공 3회 → `comfortMax += 1`, 컬렉션에 등록, 축하 연출. 단 §6 주간 상한(7일당 +2반음) 우선.
- 연속 2라운드 목표음 실패 → 다음 라운드 목표 −1(쿨다운) 후 복귀.
- 발성 팁 카드: 단계 2에서 "우/이 모음, 작은 소리로" 안내.

#### D. 풍선 메사 (Balloon) — v2
- 목적: 고음에서 강도 조절(messa di voce: 작게→크게→작게).
- 화면: 고음역 한 음을 유지하면 상대 dB에 비례해 풍선이 커졌다 작아짐. 목표 곡선(3 s 상승, 3 s 하강)을 따라감.
- 피치는 허용 오차 유지 필수. **밀어붙임 지표(§4.8) 발생 또는 상대 dB가 상한 +6 dB 초과 시 풍선 터짐** → "힘으로 올리지 않기"를 체득.

#### E. 주간 보스전 — v2
- 사용자가 목표 곡의 최고음을 한국식 표기로 선택(예: "2옥타브 라").
- 보스 HP = 현재 `comfortMax`와 목표음의 반음 차이. 그 주에 획득한 새 음마다 데미지 연출.
- 보스 도전 1회는 목 에너지 소모, 주 1회 리셋.

### 2.3 메타 시스템

| 요소 | 규칙 |

| XP | 버블 완료 20, 사이렌 회당 점수/10, 등반 발판당 5, 새 음 획득 100, 쿨다운 10, 퀘스트 완료 30 |
| 레벨 | 레벨 L 도달 누적 XP = `round(50 × L^1.5)` (L2=141, L5=559, L10=1581, L20=4472) |

| 목 에너지 | 고음역(§6) 유성음 누적 초를 배터리 5칸으로 표시. 0이 되면 고음 게임 잠금, 버블·쿨다운만 가능 |

## 3. 화면 명세

### 3.1 정보 구조
- **모바일(≤ 767 px, 기본)**: 상단 앱바(aubergine) + 콘텐츠(흰색) + 하단 탭 4개 `오늘 · 게임 · 내 음역 · 기록`. 설정은 앱바 우측 아바타.
- **태블릿/데스크톱(≥ 1024 px)**: 좌측 사이드바 260 px(aubergine) + 메인(흰색). 사이드바 항목은 채널 목록처럼 `# 오늘의 훈련`, `# 워밍업`, `# 사이렌`, `# 음계 등반` …, 구분선 아래 `내 음역 · 기록 · 업적 · 설정`. 새 퀘스트/새로 열린 게임은 **굵게**(미확인 표시), 잠긴 항목은 🔒 + 70% 불투명도.

## 4. 측정 엔진

### 4.1 오디오 파이프라인
> [검수 반영] iOS Safari 생명주기(`statechange`, track `mute/unmute/ended`, `visibilitychange`, `pagehide/pageshow`) 복구와 마이크 권한 실패 경로를 첫 게임보다 먼저 구현한다. 제약값은 보장이 아니므로 `getSettings()`로 실제 적용 여부를 확인한다(결정 D3).
```
getUserMedia → MediaStreamSource → AudioWorkletNode('capture')
  → MessageChannel → pitch.worker.ts (pitchy) → 메인 스레드 store(zustand) → Canvas/React
```
- **getUserMedia 제약 (필수)**:
  ```ts
  { audio: { echoCancellation: false, noiseSuppression: false, autoGainControl: false, channelCount: 1 } }
  ```
  켜두면 지속음이 깎이고 dB가 왜곡된다. 브라우저가 무시하는 경우 `track.getSettings()`로 확인해 `/dev/pitch`에 경고 표시.
- `AudioContext({ latencyHint: 'interactive' })`, 샘플레이트는 컨텍스트 값 사용(44.1k/48k). iOS Safari는 사용자 제스처 후 `resume()`.
- 프레임 2048 샘플(48 kHz에서 42.7 ms), 홉 512 샘플(10.7 ms) → 약 94 fps 피치 트랙.

### 4.2 피치 검출
- 라이브러리: `pitchy` v4 — `PitchDetector.forFloat32Array(2048)` → `findPitch(buf, sampleRate)` → `[hz, clarity]`
- 유성음 판정: `clarity ≥ 0.90` AND `rmsDb ≥ noiseFloorDb + 10` AND `65 ≤ hz ≤ 1400`
- 평활화: 유성 프레임 5개 중앙값(≈ 53 ms) → 판정용. 화면 선은 추가로 EMA α = 0.35.
- 옥타브 오류 가드: 직전 대비 12 ± 0.7 반음 점프가 4프레임 미만 지속 → 직전 값 유지.
- 대안(조건부): 가성 고음에서 옥타브 오류율 > 1%면 CREPE-tiny(TF.js) 보조 경로 검토 — **추가 전 승인 요청**.

### 4.3 음 표기 (`noteMath.ts`)
- `midi = 69 + 12·log2(hz / A4)`, `cents = 1200·log2(hz / targetHz)`, A4 기본 440 Hz.
- 국제식: `C4`(MIDI 60). **한국식 옥타브**: `koOct = floor(midi/12) − 3` → MIDI 60 = "2옥타브 도", 69 = "2옥타브 라", 72 = "3옥타브 도". C3 미만은 국제식만 표시.
- UI 표기 형식: `2옥타브 라 · A4` (주파수는 상세 화면에서만).

### 4.4 강도
- `rmsDb = 20·log10(rms)`. 기기 보정 불가 → **상대 dB만** 사용.
- 세션 시작 시 2 s 무음 → `noiseFloorDb` = rmsDb 95번째 백분위수.
- 온보딩 편한 "아" 3 s → `refDb` = 중앙값. 표시값 `relDb = rmsDb − refDb`.

### 4.5 유지 판정 (`hold.ts`)
- 상태: `idle → holding → success | fail`. 허용 오차 안이면 `heldMs` 누적, 이탈 150 ms 초과 시 `heldMs = 0`.
- 출력: `{ success, heldMs, centsMean, centsSD, maxRelDb }`.

### 4.6 크랙(성구 전환 끊김) 감지 (`breaks.ts`)
> [검수 반영] 이 규칙은 옥타브 오류·숨·립트릴 변조·잡음으로도 발생할 수 있어, 전문가 라벨 발성 데이터로 오탐·미탐을 평가하기 전까지 점수·목표 생성에 쓰지 않는다(결정 D2).
글라이드 중 다음 중 하나 → 크랙 1회, 발생 MIDI 기록:
1. 연속 유성 프레임 간 |Δ반음| ≥ 2.5가 2프레임(≈ 21 ms) 이내 발생
2. 유성 사이 무성 구간 30–150 ms (앞뒤 유성)

### 4.7 스피커·이어폰 처리
- 기본은 **이어폰 없음 가정**: 기준음 재생 중 + 꼬리 120 ms 동안 마이크 프레임 판정 제외. 효과음은 발성 창 종료 후에만.
- 이어폰 모드(설정): 발성 중 기준음·드론 지속 허용.
- 사이렌 가이드는 시각 전용(소리 없음).

### 4.8 밀어붙임 지표 (`push.ts`) — v2, 실험적
> [검수 반영] push 지표는 MVP 제외, v2에서도 별도 실험 승인 대상. 유성 판정(clarity ≥ 0.90)과 push 조건(clarity < 0.80)이 충돌하는 점도 정리 필요(결정 D2).
고음역에서 최근 2 s 동안 (반음당 dB 상승 기울기 > 음역 측정 시 개인 기울기 × 1.5) AND (clarity < 0.80 유성) AND (`relDb > +12`) → "힘 빼기" 소프트 힌트. **v2에서는 풍선 게임에만 점수 반영**, 나머지는 안내만.

### 4.9 음역 측정 절차 (`rangeTest.ts`)
> [검수 반영] `passaggio`는 검증 전 목표 생성(4단계 시작점)에 쓰지 않는다. 측정 후 `comfortMax` 하향 수동 조정 허용(상향 금지), 측정에도 중단 버튼·시간/시도/휴식 제한 적용, 최대 숨 길이 측정은 MVP 제외 또는 전문가 검토 후 선택형(결정 D1·D2·D3).
1. 편한 "아" 3 s → refDb (온보딩에서 했으면 생략)
2. 내려가는 사이렌 2회 → `lowest` = 300 ms 이상 유지된 유성 MIDI의 5번째 백분위수
3. 올라가는 사이렌 3회(립트릴 또는 "우", 천천히) → `highestAbs` = 300 ms 이상 유지된 최고 MIDI(반음 내림), 크랙 위치 → `passaggio` = 3회 중 2회 이상 나온 크랙 MIDI의 중앙값(없으면 null, "전환점(추정)" 표기)
4. 편한 최고음: `passaggio − 2`(없으면 `highestAbs − 5`)부터 반음씩 올리며 1.5 s, ±50 cents 유지 → 2회 연속 실패 시 중단 → `comfortMax` = 마지막 성공음. **`highestAbs` 위로는 절대 제시하지 않음**
5. (선택) 숨 길이: 편한 "아" 최대 2회 → 유성 지속 시간 최댓값
- 총 4분 이내. 4주마다 재측정 제안, 이전 결과와 차이(반음) 표시.

  ENERGY_PENALTY_RATIO: 0.5,      // 통증 ≥2 또는 쉰 목소리 ≥2 → 다음 날 50%

### 11.4 iOS Safari·실기기 시험 수용 기준

1. **기기 매트릭스**: iPhone Safari(최신·직전 iOS), iPhone 설치 PWA, Android Chrome, 데스크톱 Chrome/Safari × 내장 스피커/유선 이어폰/Bluetooth. 결과를 `PROGRESS.md`에 OS·브라우저 버전·기기·오디오 경로·시험일과 함께 기록.
2. 각 조합에서 `track.getSettings()` 결과(echoCancellation/noiseSuppression/autoGainControl 실제 적용 여부) 기록, 미적용 시 경고 표시 확인. (참고: WebKit bug 179411)
3. 기준음 재생 중 피치 오염률 기록, **'기준음만 재생' 시 성공 0건**.
4. 마이크 캡처 중 출력이 이어피스로 라우팅되거나 크래클 발생 여부 확인, 발생 시 안내(참고: WebKit bug 326286, AudioWorklet+getUserMedia 왜곡 이력 WebKit PR 9711).
5. 잠금, 앱 전환, 통화, 오디오 장치 교체, 탭 숨김 시 판정·발성 안내 중지 → 복귀 후 사용자 탭으로 재개, 필요 시 graph/stream 재생성·재보정(참고: WebKit bug 273511 — 과거 Safari 17 보고이며 현재 버전 고장의 증거는 아님).
6. 소리→화면 지연 실측 P50/P95 보고(60 ms는 가설). BT 출력 지연이 콜앤리스폰스 판정을 깨지 않는지 확인.
7. 립트릴/허밍 fixture 유성 판정률 ≥ 목표치(목표치는 M1에서 정함), 버블 완료 실패율 기록.
8. Playwright WebKit·Chromium fake input은 실제 iOS 권한·하드웨어·OS 중단 시험을 대신하지 못함 → 실기기 시험이 출시 판단의 주 근거.

### 11.5 전문가 검토가 필요한 안전 항목

- §6 상수 전체(120–300 s 예산, 90 s 워밍업, 주당 +15 s, 20/25분, 7일 +2반음)는 근거 없는 초기값임을 유지. 자동 증가(`ENERGY_WEEKLY_STEP_SEC`) 보류 여부.
- 추가 후보: `TARGET_REST_SEC`(목표음 시도 사이 최소 휴식, 예시 10 s), 통증 1 이상 시 당일 고음 게임 종료 옵션, 18세 미만·성대 질환 이력자 안내 문구.
- 진료 권장 기준: NIDCD(쉰 목소리 3주 초과 시 진료), AAO-HNS(4주 내 개선 없으면 후두 평가, 심각 원인 의심 시 기간 무관)와 앱의 '2주'·'14일 내 3회'는 다르므로 **지침에서 도출한 숫자로 설명 금지**, 더 이른 안내는 제품 정책으로 명시. 급성 호흡 곤란은 별도 즉시 도움 안내.
- 문구: '목 에너지'는 '앱에서 센 연습량'으로 설명(앱 밖 발성 미포함), "내일 다시 채워져요" → "다음 연습 전 목 상태를 확인해요" 검토.
- 최고음 끝까지 올리기·최대 숨 길이 측정의 MVP 포함 여부.
- 하트·콤보·보스전이 '힘으로 올리기'를 유도하는지, 기존 성대 질환자·청소년 고지 보강.
- 립트릴·허밍·SOVT 시연 내용.
- 검토자 역할·자격·검토일·승인 버전을 기록('원장' 명칭만으로 근거 대체 금지).
