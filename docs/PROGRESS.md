## 3. 튜닝 제안(승인 전 미반영)

- `computeHighest`는 계획대로 안정 구간 최고 MIDI를 **내림**한다. 69.0 근처를 −2 cents로 낸 경우도 68로 기록되므로, 실제 발성 데이터로 반올림(±30 cents 허용) 여부를 검토할 것.
- 립트릴·허밍 clarity 임계값, 버블 완료 실패율: 버블 시도마다 `validRatio`를 `attempts`에 저장해 두었다(JSON 내보내기로 수집 가능).
- 사이렌 1회 7 s·준비 2 s, 등반 결과 표시 1.6 s는 임의값. 실사용으로 조정.
